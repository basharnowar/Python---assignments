What return Does
return sends a value out of a function back to the place where the function was called. It also ends the function right away.

Simple Example
python
def add(a, b):
    result = a + b
    return result

total = add(3, 4)
print(total)  # 7
Here, add(3, 4) gives back 7, and we save it in total.

Why return Is Useful
You can save the result in a variable and use it later.
You can use the result in other calculations.
Your function does one job (calculate), and you decide what to do with the answer (print it, store it, and so on).
Simple Analogy
Think of a function like a vending machine. You put in money and press a button (the arguments). The machine gives you a snack (the return value). You can eat it, share it, or save it for later.

Common Beginner Mistake
Using print() instead of return:

python
def add(a, b):
    print(a + b)   # shows the number, but gives nothing back

x = add(3, 4)
print(x)  # None
print only shows a value on the screen. return gives it back so your code can use it. Without return, the function gives back None.
